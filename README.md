A [Homebrew](https://brew.sh) tap for my tools. Packages here are
generated by [GoReleaser](https://goreleaser.com) when a project cuts a
release, so they always point at the latest published binaries.

```sh
brew tap rossedman/tap
```

Or install a package directly, which taps for you:

```sh
brew install rossedman/tap/limabean
```

## Packages

| Package | Type | Platforms | Description |
|---|---|---|---|
| [limabean](https://github.com/rossedman/limabean) | Cask | macOS | Disposable Ubuntu dev VMs on your Mac, built on [Lima](https://lima-vm.io). Version-pinned toolchains, keys that never leave your Mac, and an MCP server so Claude can drive it. Installs Lima too. |
| [muscles](https://github.com/rossedman/muscles) | Cask | macOS, Linux | Explain container images, layer by layer. |
| [sarifix](https://github.com/rossedman/sarifix) | Cask | macOS, Linux | Turn any SARIF scanner into a verified auto-fixer. |
| [sminer](https://github.com/rossedman/sminer) | Cask | macOS, Linux | Find the corrections you keep making to Claude, and fix them for good. |
| [tfmetrics](https://github.com/rossedman/tfmetrics) | Cask | macOS, Linux | Org-wide metrics from statically parsed Terraform repos. |

Upgrade with `brew update && brew upgrade rossedman/tap/<package>`.

## Other projects

Not everything I build ships through Homebrew. Some of the rest:

**Claude and AI agents**

- [guardrails](https://github.com/rossedman/guardrails): makes Claude meet your standards before it can call work done. One Go binary, shipped as a Claude Code plugin.
- [tether](https://github.com/rossedman/tether): a daemon that lets AI agents observe, run and schedule work on a Linux host through systemd, under a policy the operator controls.
- [endoflife-mcp-server](https://github.com/rossedman/endoflife-mcp-server): an MCP server for querying software end-of-life dates from [endoflife.date](https://endoflife.date).

**systemd and Varlink**

- [vlx](https://github.com/rossedman/vlx): a terminal explorer for Varlink services, above all systemd's `io.systemd.*` APIs.
- [sdvarlink](https://github.com/rossedman/sdvarlink): typed, generated, tested Go clients for systemd's Varlink interfaces.
- [sdmetrics](https://github.com/rossedman/sdmetrics): connects Go and OpenTelemetry to systemd's metrics framework.
- [webhook](https://github.com/rossedman/webhook): a tiny socket-activated GitHub webhook receiver that exits once things go quiet.
- [postmarkd](https://github.com/rossedman/postmarkd): a small daemon or sidecar that delivers your apps' mail through Postmark.

**Go libraries**

- [brownout](https://github.com/rossedman/brownout): HTTP middleware for shedding traffic to selected endpoints at runtime, without a redeploy.
- [keyload](https://github.com/rossedman/keyload): reload TLS certificates and CA bundles at runtime.

**Containers and Kubernetes**

- [imagegate](https://github.com/rossedman/imagegate): a Docker authorization plugin that only allows cosign-signed images with a signed SBOM.
- [kubectl-endoflife](https://github.com/rossedman/kubectl-endoflife): a kubectl plugin that reports end-of-life information for your cluster.
